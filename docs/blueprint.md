# **App Name**: NeuroQuadAI

## Core Features:

- Login Authentication: Secure authentication process with separate login paths for students and teachers, mirroring the design of the provided image.
- Dashboard: Customizable dashboards for students and teachers.
- Mistake Mapper: AI-powered tool to analyze student mistakes and provide step-by-step corrections.
- AI Twin Profile: Maintain individual learning profiles updated using student interaction data
- AI Coaching: Summarize class performance to provide lesson plan suggestions with worksheet/quiz generation for teachers.
- Accessibility Support: Dynamically adjust content explanations for students with dyslexia, ADHD, or hearing impairments.
- EduCredits: A tool for administering points or credits for completing lessons, improvement or helping peers.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to inspire trust and intelligence.
- Background color: Light gray-blue (#E8EAF6) for a calm learning environment.
- Accent color: Amber (#FFC107) for CTAs and rewards notifications.
- Headline font: 'Space Grotesk', sans-serif, for headers.
- Body font: 'Inter', sans-serif, for main text. Paired with 'Space Grotesk' headlines.
- Use flat style icons representing different subjects or AI functionalities.
- Separate dashboards for teachers and students to customize views with interactive graphs.
- The login page will include student and teacher buttons like in the image.
